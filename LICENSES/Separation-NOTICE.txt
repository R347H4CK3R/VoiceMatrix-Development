3. VoiceMatrix inference adaptation
VoiceMatrix's Swift FFT/overlap-add implementation and NumPy diagnostic reference
are independently written to match the published Spleeter numerical contract.
The transform semantics were checked against sherpa-onnx and kaldi-native-fbank
(the latter's STFT/iSTFT and periodic-Hann behavior). Neither runtime library nor
its C++ source is included in this model pack. Their numerical conventions are
credited here without claiming that the entire app or all DSP code is an Apache
derivative or that model weights have been relicensed.

Changes relative to the published inference example: enforce 10-second bounds,
4096-sample zero guards and final hop padding, crop back to the exact input length,
use the existing ONNX Runtime CPU backend, and validate exact model hashes.
The model binaries themselves are unchanged. Their metadata field says 41000;
the published Python and C++ inference reference uses 44100 Hz, which this
integration explicitly fixes as its sample-rate contract.
