# Alternative private iPhone packaging route

The existing CircleCI VoiceMatrix project is connected. A read-only account check on 2026-11-14 showed a Free plan with 29,056 credits used and 944 remaining. This is an observed balance, not a claim that the remaining credits can finish packaging. No new pipeline was launched, no paid plan or refill was enabled, and no source was made public.

`ci/circleci/iphone-build4.yml` is an INACTIVE packaging-only candidate. It is not installed as `.circleci/config.yml`. Its `package-iphone` parameter defaults to false. It stages pinned F5, OpenVoice, ASR and diarization resources, resolves one Swift dependency graph, builds unsigned ARM64 iOS code, inspects bundled model bytes/version/build/licenses and stores the IPA plus provenance. It excludes native verification tests as requested. It maps CircleCI's commit identity into the existing source-proof tool. Config validation here is YAML parsing, Bash syntax and inspection of the reused build steps, not CircleCI server validation or a successful Apple build.

A runnable route needs an available Apple executor with sufficient included allowance, or a user-provided Mac with the supported toolchain. CircleCI eligibility, available capacity and the credit budget must be confirmed before activating this candidate; do not enable paid overage. The existing GitHub packaging run 43622398910 never obtained a runner because GitHub reported failed account payments or a spending-limit restriction. Its IPA job was skipped and it has zero artifacts. Repeating that run without resolving compute access will not create an app.

This configuration packages the current F5 standalone workflow and the verified recovery/log fixes. It does not implement offline RVC or music separation. No new build is published and no 1.0.0 completion, physical-device or voice-likeness result is claimed. A source-only or UI-fixture IPA is not an acceptable substitute for this complete bundled-model package.
