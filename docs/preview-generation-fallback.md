# Bounded fallback after unusable generated audio

The standalone pipeline previously stopped the entire job when F5 returned silent, nonfinite or too-short output, even with more reference candidates available. The existing output validity guard now throws the specific F5ChunkError.unusableGeneratedAudio. Only that error is caught in the candidate loop: release the engine, recheck cancellation/ownership, record terminal generationRejected evidence, and continue within the existing three-preview bound. Model loading, missing assets, storage failures, cancellation and unrelated generation errors still propagate. Original references and partial preview files remain retained and rejected previews are not imported.
