# Fixed speaker-mask diagnostic controls

Diagnostic only. No production model, threshold, speaker-count constraints or reconstruction changes. All seven original retained-clip regression WAVs are generated by the unchanged original builder and remain byte-identical.

Before any inference outcome, the fixed additional design is:
- First 3 seconds of source 1320 followed by first 3 seconds of 7729, with a 1-second silence and without it.
- First 3 seconds of 4446 followed by first 3 seconds of 3729, with a 1-second silence and without it.
- Each of those four first-3-second crops repeated around 1-second silence as a matched same-speaker control. Repetition is explicit, not independent utterance evidence.

The four source FLACs are pre-existing licensed LibriSpeech holdouts from earlier ASR work, not newly selected recordings or blind population samples. Exact recorded byte counts/digests are checked against the existing manifest before decode. The copied test-only assets retain original recovery provenance and attribution; no download/fallback or replacement is used.

Interpretation: segmentation masks and prepared embedding counts distinguish insufficient local-speaker separation from multiple local embeddings ending in the same cluster. This does not identify people, justify tuning to a pair, or establish calibrated accuracy. The original strict quality gate remains separate and blocking. Diagnostic reconstruction must exactly match the production pipeline for the same verified canonical clip before its evidence is interpreted. Failure remains nonzero; cases continue to retain evidence.
