# Physical iPhone offline audit (source only, not a release or installation)

This is a private-build **design and source checkpoint**. It deliberately cannot acquire models, generate an IPA, publish a release or update a feed. No device was accessed. Actual phone compilation/sideload/acceptance and licensing clearance remain open.

LiveContainer container remapping/identity is not validated, so its successful signing alone is not a preservation guarantee. No account credentials, pairing files, or new permissions are part of this procedure.

## Physical user action, after a verified private test build exists

Keep the existing VoiceMatrix installed and untouched. Sideload "VoiceMatrix Audit" as a separate app. Turn on Airplane Mode and turn Wi-Fi off. Open the audit and run phase 1. Swipe away **only** VoiceMatrix Audit, reopen, reconfirm offline and run phase 2. Keep the audit foregrounded. Its sole export button saves a newly encoded JSON to a location **you choose**; optionally share that file for verification. Never share its private diagnostics or media. If a test fails or the app exits, stop and retain the existing audit data. The public release remains untouched.

## Scope of proof

The audit calls the pinned production coordinator, store, speaker grouping, F5 engine, profile library and actual local ASR validation. Its fixed fixture begins at an acquired original receipt; it does not verify live network acquisition, identity/likeness, actual pre-existing user library migration, device-memory limits on other phones, or external publication rights. The seeded prior voice checks preservation in the distinct app. Reports omit all paths, recordings, transcript text, job/voice/process IDs and raw errors. The sandbox retains raw local evidence privately. Simulator and macOS runs cannot satisfy this audit. Backend licensing and successful phone delivery/execution are still independent gates.
