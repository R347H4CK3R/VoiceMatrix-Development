# One package-free Apple toolchain probe, no delivery

Purpose: the actual ARM64 candidate passed exact SwiftPM twice then xcodebuild inside network-denial sandbox exited 74 without a retained error. This proposal measures whether the same compiler/destination/launch command fails on a pre-defined minimal application, without starting or editing the candidate release or sending any file.

Exact base: 22ed8981299c5b65210296dd3438df14cbfd92ea / tree 8f8868b4441926d559a7845a2d25aa3c5fb56ab3. The stub uses only runner-provided Xcode 26.6 (17F113), iPhoneOS SDK 26.5, and standard system tooling. A source-only hand-written project and shared scheme bypass any XcodeGen or package download. No F5, ASR, audio, model, app bundle contents, candidate source build, signing, installation, or external fetch. The draft is deliberately inactive. If separately approved, install only under the exact toolchain branch guard with verified exact source parent; no old full build triggers there.

One unsigned build, same network denial and relevant xcodebuild flags as the failed build. Six-minute public standard ARM64 budget, no cache, artifacts, transfer, signing or paid tier. If successful, reports only a pass marker; if not, returns the original exit code. All builds and logs stay local to an owned transient folder, then are removed. Results consist of pre-defined guard tokens or an integer exit status, fixed category list, and a Swift diagnostic boolean. The classifier consumes at most 256 KiB bounded head/tail across logs; exception message/paths/raw text are not emitted. Only reads a local build log. An unknown failure remains unknown; a successful stub does not establish that the audit app builds. A sandbox IPC failure is a working hypothesis, not grounds to relax the sandbox or to retry the full build automatically.

Threat model: no secrets or external resource inputs; checkout is read-only and guarded by exact ancestry, run branch, attempt, public repo, standard runner label, and local scratch. No raw command transcripts, environment dumps, or task artifacts beyond the platform's normal visible workflow logs. Fixed outputs have no authority to claim iPhone speech, packaging, delivery, or publishing.
